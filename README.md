# HAMAREE — Luxury Perfume Store

A responsive, standalone luxury perfume storefront. Open `index.html` in a browser or upload the directory to any static web host.

## What works
- Home, men's/women's collections, shop, product details, brand story, contact, cart, checkout, and policy pages
- Search, wishlist, product gallery, quantity controls, cart drawer, cart persistence, shipping calculation placeholder
- Client-side form validation and interactive FAQs
- Mobile layout, reduced-motion support, and keyboard navigation

## Before launch
- Product visuals are custom illustrative SVG mockups, not photographs of manufactured HAMAREE products. Replace with approved product photography.
- Checkout is DEMO ONLY: orders are **not** sent to a server, captured, or paid for.
- Shipping rates, returns, privacy terms, brand contacts, and policy details need confirmation.
- Newsletter/contact form show demo confirmation only; connect a service/backend.
- Product attributes have intentionally not been invented.
- No user-account system is connected.

## Deployment
Upload all files from `hamaree-website` to a web server as-is. If using WordPress, this is a standalone frontend reference rather than an Elementor import/template.
